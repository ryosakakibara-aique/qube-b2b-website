# Definition of Done

A feature is NOT considered complete until:

### Design

- Matches Figma
- Responsive behavior implemented
- Correct typography
- Correct spacing
- Correct colors
- Correct component states

### Functionality

- Happy path works
- Validation works
- Error handling works
- Loading states work
- Empty states work

### Engineering

- TypeScript passes
- Lint passes
- Tests pass
- No unnecessary duplication
- No console errors
- No hardcoded credentials
- No unresolved TODOs

### UX

- Keyboard navigation works where applicable
- Forms provide useful validation
- Destructive actions require confirmation
- User receives success/error feedback

### Security

- Authorization checked server-side
- API inputs validated
- Sensitive data protected
- CMS permissions enforced
